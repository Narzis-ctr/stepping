# 步步 · Stepping

一步一个脚印，向上达成目标。一个对标「指尖时光」的轻量日程管理 App，核心特色是**目标层层拆解、进度自动上卷**。

单文件、纯前端、零依赖，双击 `index.html` 即可运行；也可作为 PWA 安装到手机桌面离线使用。

## 功能

- **任务提交 & 简洁 UI** — iOS 风格卡片，点圈打勾完成，已完成自动沉底划线
- **多清单滑动切换** — 日程页可左右滑动在「今天 / 工作 / 生活」等清单间切换，支持新建清单
- **任务时间** — 可为任务设置日期时间，智能显示「今天 / 明天 / 几月几日」，按时间排序
- **四级目标体系** — 底部导航：日程 / 周计划 / 月计划 / 年度目标
- **目标拆解 & 进度上卷** — 年度目标可逐级拆解到月、周、日；父目标进度由所有后代叶子任务自动计算，展开即可查看下一级完成情况
- **本地存储** — 数据保存在浏览器 `localStorage`，刷新不丢
- **PWA** — 可「添加到主屏幕」，离线可用

## 快速开始

直接双击 `index.html` 用浏览器打开即可。

### 在手机上安装（PWA）

PWA 安装需通过 http(s) 访问（`file://` 直接打开无法安装）。在项目目录起一个本地服务器：

```bash
py -m http.server 8000       # 或： python -m http.server 8000
```

- 电脑自测：浏览器打开 `http://localhost:8000`
- 手机（同一 WiFi）：打开 `http://<你的电脑局域网IP>:8000`
- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：菜单 → 安装应用 / 添加到主屏幕

## 文件结构

| 文件 | 说明 |
|------|------|
| `index.html` | 应用主体（HTML + CSS + JS 全在一个文件） |
| `manifest.json` | PWA 应用清单 |
| `sw.js` | Service Worker，提供离线缓存 |

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建步骤、无第三方框架
- 进度按「叶子任务数量均分」计算（每项权重相等）
